# THE GYM TIGER FITNESS — Luxury Athletic Club Website

A complete, high-end commercial UI/UX transformation of **The Gym Tiger Fitness**, located on Kamgar Hospital Road, Ramachandra Nagar, Sambhaji Nagar, Thane West, Maharashtra (PIN 400604).

Designed with a **Luxury Athletic Club** aesthetic inspired by prestigious private wellness sanctuaries (Equinox, Third Space, Bath & Racquets Club), featuring **Deep Emerald**, **Champagne Gold**, and **Warm Ivory** palettes, paired with elegant **Playfair Display** serif typography.

---

## 🎨 Luxury Design System

### Color Palette
- **Deep Emerald** (`#102C24` / `#091C17`): Deep, architectural dark backgrounds for high-impact visual storytelling.
- **Forest Green** (`#193D32`): Rich athletic tone for cards, badges, and the reputation carousel.
- **Champagne Gold** (`#C6A66B`): Refined luxury accent for borders, crest emblems, highlight text, and primary CTAs.
- **Warm Ivory** (`#F4F0E6` / `#FCFAF5`): Editorial light sections *(Philosophy, Programs, Masonry Gallery, FAQs)* creating a rich, rhythmic visual cadence.
- **Electric Lime** (`#C6F36A`): High-energy accent for pulse beacons, active shift badges, and recommended tier tags.
- **Pure White** (`#FFFFFF`): Crisp card surfaces on ivory backdrops.

### Typography Hierarchy
- **Headlines & Display**: `Playfair Display` (Serif, Weights 700 & 800) with responsive fluid typography (`clamp()`).
- **Body & Copy**: `Manrope` (Sans, Weights 400, 500, 600) for clean editorial reading.
- **Accents & Pull-Quotes**: `Cormorant Garamond` (Italic) for the founder's manifesto and philosophy statements.
- **Metadata**: `Space Grotesk` (Mono) for coordinates (`19.1970° N, 72.9680° E`), timings, and catalog codes.

## 💻 Tech Stack & Commands

- **React 18 + TypeScript + Vite**
- **Tailwind CSS** (Custom Luxury Emerald, Champagne Gold & Warm Ivory architecture)
- **Lenis Smooth Scroll**
- **Lucide React Icons**
- **Strictly Static Frontend**: No database, no auth, no backend server.

```bash
# Start Vite development server
npm run dev

# Compile static production bundle
npm run build

# Preview static production build
npm run preview
```
